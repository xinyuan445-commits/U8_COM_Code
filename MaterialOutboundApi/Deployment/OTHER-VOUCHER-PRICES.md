# 其他出入库单补价和历史单价备注

双击项目根目录 `Update-U8OtherVoucherPrices.cmd`，选择其他出库或其他入库，输入多个单号，空行结束，再选择是否更新原单价为 0 的行。支持逗号、逐行输入和粘贴单列表格。默认 008 账套，预览汇总后输入 `SAVE` 保存；保存成功后不审核、不回读。

交互模式每批完成或取消后自动返回单据类型选择，输入 `0` 才结束。下一批重新输入单号并选择零价规则，不复用上一批单号，也不自动重试失败单据。`-PreviewOnly` 和 `-Apply` 命令行模式仍只执行一批。保存失败或结果不明时，先核对日志及 U8 再处理。

源码根目录和服务器 `D:\MaterialOutboundApi\Update-U8OtherVoucherPrices.cmd` 都有入口。源码端使用当前 Windows 账号访问 159 的 D$ 管理共享及 SYSTEM 计划任务；服务器端直接在当前用户环境运行。当前 159 的 SYSTEM 环境创建 U8 登录组件会报 80070583，已登录用户环境组件创建成功，因此保存请在服务器桌面启动；本次规则更新未改变远程启动方式。密码只在服务器从已有 IIS 配置解密，绝不传回客户端或写入任务文件。不需要重启 IIS。

## 处理规则

- 价格来源为 `IA_Subsidiary` 的同料号、同批号、正入库数量且 `iInCost >= 0` 的记录；截至目标单据日期，按 `dVouDate DESC, AutoID DESC` 选最近一条，排除目标单自身。最近价为 0 就使用 0，不再跳过它找更早的正价；NULL 和负价不作为来源。不限制仓库，不跨批号、等级或料号回退。不直接把目标行现有单价当作历史价。
- 原单价为 NULL/空时始终补价。选择 Y 时，也更新原单价为 0 的行；选择 N 或直接回车时保留原 0 单价。已有非零单价均不覆盖。更新单价的行同时重算金额，按数量乘来源单价保留四位小数；来源为 0 时金额也为 0。
- 查到历史价的所有行都写 `最近单价：...`，包括补价行、原价为 0 的行和历史价为 0 的行（备注为 `最近单价：0`）。保留其他原备注，刷新已有独立价格说明，不重复追加。备注超过 255 字则停止该单保存，不截断。
- 缺少符合条件的价格时保留该行，列出单号、行号、料号、批号。其他可处理行照常保存；“保存成功”不代表每行均能查到历史价。
- 保存经 U8 原生 `VoucherCO.Load/Update`，不执行 SQL UPDATE，不审核或弃审。拒绝已审核、审批控制及版本变化单据；预览、Load 后重新核对行版本和取价来源。零价选项绑定预览请求与每张单的任务计划，保存时不能改选。未知保存结果不自动重试。

## 命令行

```powershell
# 只预览，不登录 U8 或保存
.\MaterialOutboundApi\Deployment\Update-U8OtherVoucherPrices.ps1 -VoucherType 08 -VoucherCodes 0000005818,0000005819 -PreviewOnly -ReplaceZeroPrices:$false

# 用户明确选择直接保存，仍先检查快照；无二次人工提示
.\MaterialOutboundApi\Deployment\Update-U8OtherVoucherPrices.ps1 -VoucherType 09 -VoucherCodes 0000006579 -Apply -ReplaceZeroPrices
```

可选 `-Database 998`。不指定 `-ReplaceZeroPrices` 时先询问；显式 `-ReplaceZeroPrices` 表示更新 0 单价，`-ReplaceZeroPrices:$false` 表示保留。`-Apply` 仍先预览，但未指定该选项时也会询问。任务快照、输入、选项、修改 XML、逐行缺价说明和结果保留在服务器 `D:\MupiOtherVoucherPriceJobs\<任务ID>`。超时或网络中断须先检查该任务的 Save-response.json、save-attempted.txt、u8-save-success.txt；不要盲目新建任务重放未知结果。

另 51 行没有符合原取价条件的历史价（其他出库 9 行、其他入库 42 行）。同料号、批号及目标日期范围内，采购入库 01、其他入库 08、产成品入库 10 的正数量正单价记录中也没有可用来源（排除目标入库单自身）。当前单价可能由盘点账面金额带入，不能据此认定存在历史入库价。

本次检查只读，未补写这 12 行或修改其他既有单据。用户运行本脚本并保存后，可补写其中仍未审核、状态未变且仍能取到历史价的备注。
