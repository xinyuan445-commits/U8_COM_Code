# Excel 导入盘点单

启动项目根目录 `Import-U8InventoryCountExcel.cmd`，输入填好的 `.xlsx` 路径。服务器入口为 `D:\MaterialOutboundApi\Import-U8InventoryCountExcel.cmd`。模板填写工作表必须叫“盘点导入”，第一行列标题不变，第二行开始填数据，无需安装 Excel。

模板列：分单标识、仓库编码、料号、盘点数量、批号、货位名称、单价、部门编码。

- 仓库和料号必填，批号按存货要求填写。编码、批号、货位名称和分单标识必须为文本；数量和单价为数值，允许 0，空白不等于 0。数量最多6位、单价最多10位小数，不接受公式。
- 货位填**名称**，不是编码。仓库管理货位而未填、货位不在该仓库或名称重名时停止；非货位仓库须留空。
- 部门编码可逐行填；留空时脚本要求输入默认部门。相同分单标识、仓库和部门合成一组；分单标识留空按仓库和部门分组。例如 PD01 两行、PD02 一行，同仓库同部门生成两张单。不同仓库或部门永不合在一张单中。
- 每组超过1000行自动拆单。同组存货、批号、货位和全部自由项重复会拒绝，包括跨拆单边界的重复，不自动合计。
- Excel 只决定导入的明细，不自动补整个仓库其他库存。账面数由 API 取 U8 当前结存；实盘数和单价按 Excel 输入。未传账面数或金额，不用历史价格覆盖输入的0价。辅计量、保质期处理沿用当前 API：辅单位及换算率取档案；保质期默认到单据年份12月31日，失效日期为次日。
- 存货等级等必需自由项从同仓库、料号、批号和货位库存中唯一匹配后带入；没有唯一匹配则拒绝，不猜填。可在 Excel 右侧增加“自由项1”至“自由项10”文本列明确填写。辅数量默认按 API 的固定换算率计算；本模板不覆盖自由换算辅数量、批次属性等高级字段，需要时使用通用盘点 API。

默认账套008、单据日期为首次导入当天，所有单据**未审核**。脚本先校验全部待导入单据，显示分单数量，输入 `CREATE` 才提交。成功返回即记录单号，不审核，不直接写 SQL。

```powershell
# 只读查询及 API 校验，不创建单据
.\MaterialOutboundApi\Deployment\Import-U8InventoryCountExcel.ps1 -ExcelPath 'C:\盘点.xlsx' -DepartmentCode '部门编码' -DryRun

# 指定账套和日期，仍需交互输入 CREATE
.\MaterialOutboundApi\Deployment\Import-U8InventoryCountExcel.ps1 -ExcelPath 'C:\盘点.xlsx' -Database 008 -VoucherDate '2026-10-07'
```

服务器读取 IIS 的 LocalMachine DPAPI 配置；源码端读取仓库根目录 `.env.local` 的 SQL 和 API 连接。配置、凭据与密钥不写入任务日志。无需变更 API DLL、接口路由或重启 IIS。

## 重复导入与部分失败

任务日志在服务器 `App_Data\InventoryExcelImports`，源码端在当前用户 LocalAppData 的 `MaterialOutboundApi\InventoryExcelImports`。Excel 文件字节摘要、账套、API地址和可选 ImportBatch 共同标识导入；同一文件重复运行复用原日期、默认部门、精确请求 JSON 和幂等键，已成功项跳过。日志包含明细、分单与结果，请按业务敏感数据保护。

创建前写 Sending 标记；成功后保存单号和 Created 状态。遇到报错、网络中断或回包异常时记录 Unknown，停止后续单据，**不自动重放未知结果**。即使是业务校验失败也先核对，不自行清状态。检查 `state.json`、IIS日志和 U8 单据后再处理；成功单据不回滚、多张单不是原子事务。

不要删除日志、改文件、改日期部门、切换电脑或换批次来规避未知状态，否则可能重复生成。CLI `-ImportBatch 新标识` 会开启新任务，只用于已经确认需要重新生成同一文件的业务操作。不同文件字节（含仅重新保存Excel）是不同任务；脚本无法凭内容相似保证跨文件去重。服务端幂等与本机文件锁提供补充保护，不等同跨电脑任务锁。

模板标题采用浅蓝底、深蓝加粗，标识字段预设文本格式。样式预设到201行，继续向下填写不影响导入；一次最多100000行，XML大小还有安全上限。
